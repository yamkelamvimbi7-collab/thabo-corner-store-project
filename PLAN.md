Thabo's Corner Store Project Plan

1.Decomposition

I will divide the project into smaller tasks: cleaning the raw data, creating the database, analysing sales, generating charts, adding password protection, and documenting the results.

2.Pattern Recognition

I expect to find missing values, inconsistent product categories, different date formats, duplicate records, and sales that refer to product IDs that do not exist.

3.Abstraction

I will focus on useful business information, including revenue per product, popular products, monthly sales trends, and payment methods. I will connect sales to products using product IDs.

4.Algorithm and Order of Work

Inspect the products and sales CSV files.
Clean missing, duplicate, inconsistent, and invalid data.
Create the products and sales tables in SQLite.
Write SQL queries to answer business questions.
Analyse sales using Python functions, loops, lists, and dictionaries.
Generate a bar chart and a monthly sales line chart.
Implement password hashing and a security gate.
Test the program, document the findings, and commit progress to GitHub.

5.Testing

I will check that the cleaned data is consistent, the database relationships work, the SQL queries return useful results, the program runs without errors, both charts are generated, and reports are protected by a password
